# MarketHub AI · Matriz de máxima funcionalidad FREE y PRO
**Propuesta de producto fechada 2026-11-04. No equivale a funciones activadas.**

## Objetivo
Permitir al usuario realizar prácticamente todo el ciclo de marketing desde un mismo sitio: investigar, planificar, crear fotos/diseños/vídeos/textos, publicar, anunciar, conversar, captar clientes, vender, automatizar y medir resultados.

**FREE** será realmente útil, con herramientas de la mayoría de familias y cuotas para controlar costes; con publicidad identificada y recompensas voluntarias. **PRO** ofrecerá todas las familias, funciones avanzadas, volúmenes mucho mayores y **cero anuncios**. Nunca se eliminarán capacidades previas para simplificar.

## Límites orientativos pendientes de estudio de costes y normativa

| Característica | FREE con anuncios | PRO sin anuncios |
|---|---|---|
| Cuota | 0 € | 29,90 €/mes IVA incluido, referencia provisional |
| Marcas | 1 | 5 |
| Cuentas sociales conectadas | 4, sujetas a API | 20, sujetas a API |
| Publicaciones efectivas / mes | 20 | 500, bajo uso razonable |
| Textos IA / mes | 30 | 1.000 (complejidad limitada) |
| Imágenes IA / mes | 3 | 50 |
| Vídeos generados IA | Pruebas puntuales por créditos opcionales | 10 clips cortos estándar |
| Editor manual y plantillas | Básico útil | Avanzado profesional |
| Histórico analítico | 90 días donde disponible | 24 meses donde disponible |
| Competidores analizados | 3 | 30 |
| CRM | 100 contactos | 10.000 contactos |
| Landing / link en bio | 1 página | 20 páginas |
| Email marketing | Cuota reducida por definir | Cuota profesional por definir |
| Equipo | 1 usuario | Hasta 5 colaboradores |
| APIs y webhooks | Integraciones simples | Integraciones avanzadas |
| Informes | Básicos | PDF/CSV/PPT personalizados |
| Publicidad dentro de la app | Sí | **No** |
| Publicidad recompensada | Opcional | No necesaria |
| Campañas publicitarias de clientes | Básicas según integración | Avanzadas según permisos |
| Seguridad, privacidad, exportación | Incluidas | Incluidas con controles de equipo |

**Nota:** todas las cifras están por validar con costes de IA, edición, email, APIs, anuncios y almacenamiento. La inversión publicitaria en Google/Meta/TikTok no se incluye en ningún plan. No se promete IA ilimitada ni ingresos por publicidad.

## Plan de implementación por valor
1. Base operativa: cuentas, backend, perfiles, primeras conexiones OAuth autorizadas, creación real de contenido, editor/exportación, publicación fiable, analítica conectada y planes de uso.
2. Monetización segura: AdMob/alternativa web cuando proceda, RGPD/CMP, ingresos recompensados opcionales, suscripciones con verificación y protección antifraude.
3. Marketing completo: CRM, email, landings, links en bio, ventas, campañas, escucha, SEO social, competidores y reportes.
4. Avanzado: herramientas de agencia, editores profesionales, agentes IA con aprobación, automatización multicanal, atribución y creadores.

## Restricciones técnicas y legales
- Cada red tiene sus límites de API, permisos, cuotas y requisitos de revisión. Nunca publicaremos por métodos inseguros ni prometeremos funciones que no autorice la red.
- No ejecutar campañas, enviar mensajes masivos ni gastar presupuestos sin permisos y confirmación.
- La app no debe confundir demos con funciones reales; el estado se muestra en el catálogo.
- Guardar todos los proyectos y capacidad de exportarlos; evitar pérdidas al cambiar de plan.
