## Compatibilidad
Las APIs oficiales tienen limitaciones por plataforma. Incluso herramientas consolidadas no pueden ejecutar todas las funciones dentro de Instagram, TikTok, LinkedIn, YouTube, Threads o Pinterest. Se mostrará disponibilidad por red y alternativa de exportación/manual cuando corresponda.
